# 经方数据（伤寒论 + 金匮要略）

本目录收录《伤寒论》与《金匮要略》的方剂结构化数据，共 **256 首方 / 295 个版本 / 1399 味药**。

## 数据来源与版权

| 来源 | 性质 | 原文收录 |
|---|---|---|
| 《伤寒论辑义》（日·丹波元简，1801） | 公有领域 | ✅ 保留 `composition_text` |
| 《金匮要略》注释本 | 现代注本，有版权 | ❌ 原文已移除，仅保留结构化组成 |

**为什么这样处理**：方剂的组成（药名、剂量、炮制）是事实性信息，可以公开；但现代注本的整理文字受著作权保护，公开分发有风险。因此：

- **结构化数据全量公开**：药名、剂量、炮制、所属方、来源标注
- **原文片段仅保留公有领域部分**：丹波元简《伤寒论辑义》成书于 1801 年，已进入公有领域
- 金匮部分的 `composition_text` 为空，并带 `composition_text_removed` 说明

## 文件

- `formulas.json` — 全部方剂数据

## 数据结构

```jsonc
{
  "formulas": {
    "桂枝汤": {
      "name": "桂枝汤",
      "sources": ["伤寒论辑义"],
      "version_count": 1,
      "versions": [
        {
          "source": "伤寒论辑义",
          "composition_text": "桂枝（三两去皮） 芍药（三两）…",   // 仅公有领域来源有值
          "declared_count": 5,          // 原文自报味数（「右五味」）
          "source_defect": null,        // 解析味数与声明不符时非空
          "components": [
            {
              "herb": "桂枝",           // 原文写法
              "herb_std": "桂枝",       // 归一后的标准名
              "dose": "三两",
              "processing": "去皮",
              "missing_dose": false,
              "shared_dose": false      // 剂量来自「各X两」时为 true
            }
          ]
        }
      ]
    }
  }
}
```

## 重要声明

1. **剂量为汉代原量，未做单位换算**。汉代一两约合今 13.8g（一说 15.6g），一斤为十六两。不可直接作为现代临床用量。
2. **`source_defect` 字段**标记了「解析味数与原文自报味数不符」的方，共 21 个。这些方的原文可能有校注混排或底本断裂，使用前应回看原件。
3. **`missing_dose: true`** 表示原文该味药未标注剂量（约 4.8%），不是数据缺失。
4. **同名方不合并**：两书都收录的 39 首方保留为 `versions` 数组，因为不同版本的组成可能不同（如桂枝加桂汤的芍药三两 vs 二两）。
5. **本数据不构成医疗建议**。方剂的使用须由具备资质的中医师辨证决定。
