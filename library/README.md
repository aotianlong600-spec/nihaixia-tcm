# 经方数据（伤寒论 + 金匮要略）

本目录收录《伤寒论》与《金匮要略》的方剂结构化数据，共 **256 首方 / 295 个版本 / 1399 味药**。

## 数据来源与授权状态

| 来源 | 性质 | 授权状态 |
|---|---|---|
| 《伤寒论辑义》（日·丹波元简，1801） | 公有领域文献 | ✅ 已进入公有领域 |
| 倪海厦《金匮要略》注释本（人纪系列） | 现代讲稿 | ⚠️ **著作权归倪海厦及汉唐中医所有，本仓库未获明示授权** |

**关于授权**：本仓库收录倪海厦讲义的方剂组成片段（共约 4,700 字），用于中医方剂的学术整理与检索。若权利人认为不妥，请联系仓库所有者，将立即删除相关内容。

## 数据结构

```jsonc
{
  "formulas": {
    "桂枝汤": {
      "name": "桂枝汤",
      "sources": ["伤寒论辑义"],
      "version_count": 1,
      "versions": [
        {
          "source": "伤寒论辑义",
          "composition_text": "桂枝（三两去皮） 芍药（三两）…",
          "declared_count": 5,          // 原文自报味数（「右五味」）
          "source_defect": null,        // 解析味数与声明不符时非空
          "components": [
            {
              "herb": "桂枝",           // 原文写法
              "herb_std": "桂枝",       // 归一后的标准名
              "dose": "三两",
              "processing": "去皮",
              "missing_dose": false,
              "shared_dose": false      // 剂量来自「各X两」时为 true
            }
          ]
        }
      ]
    }
  }
}
```

## 重要声明

1. **剂量为汉代原量，未做单位换算**。汉代一两约合今 13.8g（一说 15.6g），一斤为十六两。不可直接作为现代临床用量。
2. **`source_defect` 字段**标记了「解析味数与原文自报味数不符」的方，共 21 个。这些方的原文可能有校注混排或底本断裂，使用前应回看原件。
3. **`missing_dose: true`** 表示原文该味药未标注剂量（约 4.8%），不是数据缺失。
4. **同名方不合并**：两书都收录的 39 首方保留为 `versions` 数组，因为不同版本的组成可能不同（如桂枝加桂汤的芍药三两 vs 二两）。
5. **本数据不构成医疗建议**。方剂的使用须由具备资质的中医师辨证决定。
