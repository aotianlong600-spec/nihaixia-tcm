# 倪氏个人辨证资料工作台 0.4.1

以Windows电脑为中心，供本机网页、局域网网页与安卓使用同一知识库及辨证引擎。延续个人自用流程，无规则审核、医师签名或发布审批。原文映射与决策逻辑维持独立来源边界，本版新增多端访问和Codex授权。

## 本机使用

双击交付目录“启动工作台.cmd”，打开 http://127.0.0.1:8765。停止使用“停止工作台.cmd”。本机已有资料保留在原工程data；源代码包不包含原件、数据库、病例或密钥。

在新机器准备Python 3.11（setup会安装项目内固定Node运行时），运行setup.cmd及start.cmd。恢复已有加密备份可带回原件与不可变映射包；也可先导入同哈希原件，再执行：

```powershell
python scripts/import_decision.py '倪氏太阳方证_原文映射包_v5.json' --data-dir data
```

导入核对原件SHA、原文切片/哈希、引用、表达式和版本；同id/version不得覆盖。映射包修订号与原件处方记录版本是不同概念。

## 本轮知识与逻辑

全库可检索17份来源：12 PDF共3036物理页、5份非PDF共307块。519页有OCR记录，497页非空；未逐字校勘、双栏顺序未全部重建。

首个原文映射包覆盖1份原件9页：桂枝汤、桂枝加葛根汤、葛根汤、麻黄汤、桂枝加厚朴杏仁汤，5个独立处方版本、29味条目、34个原文锚点、132条断言；6节点、21条件、6个来源情境、4条关系边。其余资料仍待按相同结构逐条对应，不能将资料已导入称为医学知识已结构化。

现有314方/315候选记录仍是外部开源目录的召回层；5项同名目录关联不合并原量，也不把其他开源条目升级为倪氏规则。本地原有匹配按钮属于线索召回；新决策图进入每次问诊上下文，并提供专用API及逐项溯源文档；本轮未新增树形界面。

程序独立评估每个来源情境，保留多个候选、未知、反证和冲突；特定情境里的AND不等于全局必要条件，原文OR保留。已确认的当下本人事实参与，既往/家属/未确认不冒充当前。原始聊天不自动变成已确认事实；AI负责理解与解释，不能把既往AI发言当医学依据，也不能改写冻结的程序结果。缺数值或单位时仍补问，已解决的条件不重复问。

经典、讲解、医案、编注、参考作者、开源归纳及AI推演分别标记；本包主要是原件所引经典和讲解，另有29条图像转录方式的字段整理。仅AI/开源摘要不能支撑可执行情境、硬条件或方药字段；个案不能单独支撑全局必要/排除/病程。层级标签不证明作者身份或医学有效性。

方名、药味、炮制、原量、单位、煎服分别关联断言和原文；未标注留空，不换古今量，不作个人日量。两组真实加味含3个具体动作，差异已计算，但因缺项与版本差异回退，成功合方0；不补造调量。模型若提供与所选版本冲突的药味或煎服，会明确拒绝；可以留空按该版回填。加减直接标明已应用/未应用及原因，未应用不会藏在详情里。

## 模型与数据

0.4.1增加命名模型配置的新增、选择、删除和独立加密API密钥；删除当前项后不会自动改用其他提供方。Codex配置共用一份账号授权。浏览器不能自动回调时，可把本轮完整回调网址填回工作台，不能使用request_id或账号ID。Windows版固定项目内Node 24.22.2，以避开旧运行时授权完成后的原生退出崩溃。详见docs/OAUTH_TROUBLESHOOTING.md。


支持API Key兼容Chat Completions，以及独立Codex账号授权（Pi AI 1.3.0文本通道）；浏览器/设备码登录由本人在OpenAI网页完成，授权DPAPI加密保存在电脑端。不读其他软件账号，不启用编码Agent工具。默认不外发；启用并主动发送后会发送问诊单、最近12条对话及选取书证与结构图。模型密钥和授权不进入备份。真实账号授权、额度与实际模型效果须单独验证。

0.4新增同一电脑中心的网页和安卓：本机HTTP8765，设置访问密码后可显式启用LAN HTTPS8766；安卓复用Vue页面与同一数据库，绑定本机CA公钥，无离线病历。运行与配对步骤见 [多端使用说明](docs/多端使用说明.md)。公开仓库只同步源码，原件、病历、凭据、证书和实际地址均留在本机。

图、断言、来源和实际结果冻结进会话；包改版或来源文字变化，旧结果标记过期。完整图快照保留本机；模型请求去除重复包快照，但保留同次条件trace和来源。首组一份合成输入的请求实测181750 UTF-8字节，不等于token数；后续扩展多组需限制相关包召回，当前不声称全库推理性能已验。

加密备份使用至少12字符口令，包含一致数据库快照、登记原件与哈希；上限512 MiB，不含密钥。恢复到不存在或空目录，不覆盖旧数据：

```powershell
python scripts/restore_backup.py 'D:\backup.tcmbak' --destination 'D:\tcm-restored'
powershell -NoProfile -File start.ps1 -DataDirectory 'D:\tcm-restored'
```
