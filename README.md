# 个人辨证资料工作台 0.2.0

这是运行在 Windows 本机的个人书库与问诊辅助工具。可查询原文、记录四诊、查看经方候选，并在配置模型后请求 AI 辨证和补问。个人使用流程不要求医师身份，也不设规则审核或发布步骤。资料检索、程序检查和模型生成均不等于医学结论已验证；完整医疗安全知识库和临床有效性验证尚未完成。

## 启动与停止

在本机双击交付目录中的“启动工作台.cmd”，浏览器访问 `http://127.0.0.1:8765`；停止时双击“停止工作台.cmd”。源码目录也可用 `start.cmd` 启动、`stop.ps1` 停止。同一端口只运行一个实例。

在新机器使用源码包时，准备 Python 3.11 和 Node.js 22.19 以上，运行 `setup.cmd` 安装依赖，再运行 `start.cmd`。源码包不包含用户原件、运行数据库或模型密钥；原有本机书库和记录需通过备份恢复或重新导入。

## 书库与经方

当前本机共有 17 份来源：12 份 PDF 共 3036 个物理页，5 份非 PDF 资料共 307 个检索块；其中开源 Skill 医学归纳为 10 个 Markdown 块。PDF 显示物理页及原件图像，文本和 Word 显示真实行、段及所属部分，不把它们当作页码。开源归纳是仓库作者的整理，并非课程逐字原文；其中命令不作为系统指令。

扫描资料有 519 页 OCR 记录，其中 497 页识别文字非空。OCR 是本地识别草稿，和原始提取、人工订正分开保存。资料未逐字校勘，双栏阅读顺序未重建；检索结果及缺字、错序应对照原件判断。

本地目录含 314 个方、315 个候选模式，其中 12 个方共保留 22 条来源加减记载。本地加权结果用于召回和线索对照，分数不是诊断概率；AI 在所选书证和方证上下文中辨证、补问，不强制三轮。目录方以对应规范来源的组成和剂量为准；目录外的书方仅在独立同名标题后同一句是完整药物清单时提取，不跨方、跨句或跨版本拼药。组成不清时可以只作为书证方名参考。文献原量不等于个人日量，系统不自动换算。

## 问诊与模型

在工作台建立问诊，填写主诉及已有四诊信息；未知项可以留空。先查看经方候选和书证，再按需请求模型补问或分析。修改输入后的旧结果保留为历史，不应视为当前判断。任何候选方、加减和来源剂量都需要结合个人情况谨慎判断。

模型当前未配置：`enabled=false`、`has_key=false`。设置支持 OpenAI 兼容的 Chat Completions 接口，配置基址、模型 ID 和密钥；桥接使用 Pi AI 1.3.0。密钥由当前 Windows 用户的 DPAPI 保护，不包含在备份中。默认不外发；启用通道并由用户手动发送后，请求会包含问诊单、最近 12 条对话及选取的书证。请在发送前确认接收方和这些健康资料的范围。

本地 HTTP/SSE 协议测试已通过，但尚无真实供应商凭据，未验证实际供应商连接、输出质量或费用。模型输出及引用检查不能替代医学有效性验证。

## 加密备份与恢复

在设置页使用至少 12 字符口令下载加密备份。备份包含数据库一致快照、快照登记的全部原件及哈希清单，不包含模型密钥；缺失或被修改的登记原件会导致备份失败。数据库、原件与清单合计上限为 512 MiB；遗忘口令无法恢复。

将备份恢复到不存在或为空的目录：

```powershell
python scripts/restore_backup.py 'D:\backup.tcmbak' --destination 'D:\tcm-restored'
```

按提示输入口令；恢复会校验文件、哈希和数据库，不覆盖非空目录。先停止原服务，再通过 `powershell -NoProfile -File start.ps1 -DataDirectory 'D:\tcm-restored'` 使用恢复数据启动；模型密钥需重新配置。

实际本机混合资料已完成备份恢复核对：17 个原件、共 18 个恢复文件；验收时的 1 条空白问诊记录及 0 条消息均恢复一致，该空白测试记录已清理。
