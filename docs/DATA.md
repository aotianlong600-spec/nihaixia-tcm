# 空知识库数据契约

## 当前分发内容

旧仓库的医学索引与方剂组成数据已于 2026-11-14 清空。`library/` 中的旧方剂组成数据已删除；`app/resources/open_formula_library.json` 仅保留以下结构：

```json
{
  "formulas": [],

```

该文件继续存在是为了保持读取接口可用，不代表仍有内置医学知识。新数据目录下，`/api/overview` 的方剂、证型、原文和来源计数均为 0，`/api/formulas` 返回 `{"total": 0, "items": []}`，方剂详情返回 404。

## 保留的能力与资料

- 原文导入、单元读取、检索、物理页、印刷页和原文锚点能力继续保留。
- 有权限的调用方可通过现有导入接口重新导入资料；写入仍要求 `X-Write-Token`。
- 本机原始资料、病历、模型配置及浏览器资料未被本次仓库清空操作删除；更新源码也不会清空已有 `data/` 目录。
- 不自动下载或重新打包旧知识包，不恢复旧加权规则、六经字段或旧算法中间产物。
- `tcm-study-brain-v2` 是独立项目，不在本次修改范围内。此仓库不增加算法、问诊或模型接入。

## 后续数据边界

新资料需要明确其导入范围；第三方资料标记为「第三方」，以倪海厦学术体系为主线，版本差异不静默合并。已有倪师原文引用继续对应原件。剂量保持来源原量，缺失留空，不自动换算或补造。

本次仅清理当前树，不重写 Git 历史。测试使用独立的合成目录验证名称、证候和药味检索，以及详情读取，不把测试条目作为分发的医学数据。
