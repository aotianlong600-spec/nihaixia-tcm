# 旧知识数据清空（2026-11-14）

本次按项目所有者要求清空旧知识库、索引与算法派生产物，保留原始资料、病历及模型配置。后续应用将参考所有者仍在优化的 [中医大脑](https://github.com/aotianlong600-spec/tcm-study-brain-v2)，本次没有修改该仓库，也没有将它的当前版本作为定版内容复制过来。

## 当前仓库

- 移除 `library/` 的旧方剂组成数据。
- `app/resources/open_formula_library.json` 保留合法空目录，读取接口可正常返回零条数据，后续可按新方案重新导入。
- 移除旧网页自动发布工作流，停止从旧知识包 Release 重新灌入数据。
- 算法层与应用层已在此前版本移除；本次不恢复旧算法。
- 不改写 Git 历史；历史提交中的旧文件仍可回溯。

## 本机清理边界

本机 SQLite 按知识/规则表清空，保留病历与历史对话、历史分析记录，并对保留行与原件、配置文件做清理前后哈希核对。原始 PDF、文稿和模型凭据不删除。

历史病历内的旧分析作为历史快照保留，不能作为新引擎的现行知识。加密备份和其他浏览器的离线副本不属于仓库当前分支，不能通过删除源码同步擦除。公开主分支清空也不等于历史提交、已有克隆或下载副本已经消失。
