# 本地知识库与安卓独立运行设计

目标：离线中医原文、方证及经方加减算法，加上按需调用的云端模型。网页和安卓保留现有界面与来源约束，安卓不依赖电脑、同一局域网或本机CA配对。

## 执行方式

- 电脑网页使用本机 Python/SQLite 服务，首次启动可导入放在 `knowledge/` 的自备知识包。病例与凭据保存在本机。
- 安卓内置 Vue 静态页面、SQLite知识包及 Chaquopy Python 3.11 运行时，直接复用 Python 医学引擎。原文码点偏移、规范JSON哈希及数值比较不移植为第二套医学逻辑。
- 从 personal.py 提取纯 Python 业务核心；桌面继续使用 Pydantic，移动端使用从相同模型生成的固定JSON schema校验。以同一组合成用例比较结果。
- 安卓通过限定到应用页面的原生桥调用本地API。云端HTTPS由原生网络层执行，凭据由 Android Keystore 保护；原文页面由原生 PDF 渲染器显示。
- 云端API Key支持当前兼容接口、模型及思考档位。Codex保留独立设备授权，移动端不复制电脑的登录文件，不依赖Windows DPAPI或Node运行时。

## 知识与个人数据

导出程序从本地库读取知识表，写入全新 SQLite 文件，并收录已登记原件、方剂索引及完整性清单。更新知识时仅事务性合入知识表，原件与映射版本冲突时中止。病例和凭据独立保存。

公开仓库提供开源经方索引。构建安卓时可以提供本地知识包，或用 `scripts/create_empty_knowledge_pack.py` 生成含开源索引的空包。

## 边界与验收

取消电脑服务器地址、私有IPv4和固定CA依赖；HTTPS正常证书验证、原文溯源、缺量留空和冲突提示继续执行。

验收包含纯核心不导入FastAPI/Pydantic/Node、旧测试回归、知识包不含病例与凭据、离线建档检索/鉴别/加减、云端合成输入调用、安卓单测/编译及可用设备测试。没有实测的设备或模型必须说明。
