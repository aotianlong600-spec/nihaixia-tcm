# 安卓独立离线版

安装包ID：com.nihaixia.local，版本0.5.0。与旧电脑客户端包名不同，可同时保留。

APK 内置 Vue 页面、构建时提供的知识包和共享 Python 算法。首次准备资料后可离线检索经方，原件查阅及来源图规则计算使用包内资料。AI 问诊使用你配置的云模型。

不填写电脑地址、不要求同网、不绑定电脑CA。HTTPS按Android系统正常验证。API密钥与本应用Codex令牌由Android Keystore加密，不进入知识包或GitHub。

在“模型与数据”配置云端模型并启用，再在问诊页选配置/模型/思考档位并应用。Codex使用设备码，由本人在系统浏览器完成授权；无电脑localhost回调。

原文图片按PDF物理页打开，印刷页另列。各设备记录不自动同步。当前安卓尚未提供病例备份导入/导出；卸载或清除数据会删除本机记录。桌面仍保留原加密完整备份格式。

公开仓库提供构建源码和开源经方索引。把自备知识包放入 `knowledge/`，或运行 `python scripts/create_empty_knowledge_pack.py` 生成仅含索引、语料和来源图均为空的包。具体构建命令见 [README](../README.md#构建安卓)。本机 debug 签名用于后续覆盖安装。
