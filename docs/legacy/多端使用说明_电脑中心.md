# 本机中心网页与安卓

代码公开；原件、病历、数据库、模型授权、局域网证书和运行日志仅在本机。GitHub同步源码不等于同步病历，多个终端通过同一台电脑读取同一数据库。电脑休眠、关机或离开该局域网时手机无法访问。

## 电脑与访问密码

1. 运行 `start.cmd`，打开 `http://127.0.0.1:8765`。
2. “模型与数据 → 工作台访问与多端”设置12至256字符访问密码。以后电脑和手机都用此密码登录。它与OpenAI账号密码不同。
3. 停止原服务，再运行 `start-lan.cmd`。该进程同时提供本机HTTP8765和局域网HTTPS8766；脚本显示实际私有IPv4地址和CA指纹。不会修改Windows防火墙。
4. 手机和电脑连接同一可信局域网。Windows如阻挡入站，仅为该Python程序的TCP8766放行“专用网络/本地子网”；不要配置路由器公网端口转发。

显示的地址可能包含虚拟网卡；选择与手机所在局域网对应的地址。换网或IP变更后重启局域网服务以更新服务器证书；CA未改变时不需重建APK。

首次设置仅允许真实本机回环连接，Host或X-Forwarded-For不能替代。访问会话8小时后失效，重启服务后也需重新登录。退出只影响当前设备。密码遗失时，在电脑停止服务，保留并重命名 `data/access.json` 作备份，再以本机模式启动重新设置；切勿在运行中删除配置。

## HTTPS与安卓配对

`python scripts/prepare_lan.py` 生成/复用 `data/lan/` 中的本机CA和服务器证书；其中 **ca.pem是公钥证书**，ca-key.pem/server-key.pem是私钥，不能上传或传给手机。证书初次生成后应保留，IP变更可在同一CA下重签服务器证书。

安卓APK构建时绑定本机CA公钥，按 `docs/ANDROID.md` 构建并安装，输入启动脚本显示的HTTPS局域网地址；无默认密码和默认服务器地址。不需要忽略证书错误。不同电脑/重新生成CA后，需要用相应CA重新构建配对APK。

其他设备的网页浏览器需要先从可信电脑获取ca.pem，核对启动脚本显示的SHA256证书指纹，再在自己设备中安装为信任的证书。不要点击跳过TLS警告。不愿安装根证书时使用已配对安卓APK或电脑本机网页。证书信任/设备管理步骤依具体系统而异，程序不自动更改系统信任。

手机支持问诊、候选解释、书库文字与原件页面图像；大型原件和加密备份在电脑网页下载。本版不提供离线病历、云同步或公网服务。

## Codex登录与API Key

在“模型与数据”选择连接方式：

- API Key：保留现有兼容接口，填写HTTPS API基址、模型ID和密钥。
- Codex账号授权：推荐“设备码登录”，在OpenAI授权页输入显示的设备码并由本人登录；手机授权页在系统浏览器打开。电脑浏览器登录方式须在运行后端的电脑完成localhost回调。工作台不索取OpenAI密码，不读取其他软件的登录文件。

授权完成后，选择/填写账号可用的模型，启用服务、选择是否允许外发必要症状与书证，保存配置，再“测试已保存的配置”。SDK目录只是模型名称清单，不能证明账号权限或额度；只有实际请求完成才证明本次模型通道可用。无法授权时可取消、重试或继续使用API Key。

本应用独立保存Codex授权，用Windows当前用户DPAPI加密，手机不接收模型令牌。“退出Codex授权”移除本工作台授权并取消相应模型任务，不影响其他软件的账号。取消不保证供应商已停止计费。

## 备份与更新

加密备份格式沿用现有格式，包含数据库及登记原件，最大512 MiB。模型密钥/OAuth、访问密码与TLS证书不在此备份内；迁移电脑时要另行安全保管本机配置或重新设置/配对/登录。恢复到空目录，先保留旧数据。GitHub更新只更新代码，不要用空data覆盖原data。

原文逐项结构化仍只覆盖首组方证；医学资料导入不等于全部规则建立。软件回归检查不证明真实病例有效性。真实账号与手机联调的实际验收状态以本次交付记录为准。
