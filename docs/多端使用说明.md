# 本机网页与独立安卓

电脑网页在本机 http://127.0.0.1:8767 运行；安卓内置相同知识资料与Python算法，可独立使用。手机不再依赖电脑、局域网地址或固定CA。

两端可使用同一份本地知识包，分别保存病例和模型凭据。公开源码版带开源经方索引，个人知识资料留在设备上。安卓构建可使用自备包，或按 [README](../README.md#构建安卓) 生成空包。

离线可查书、检索经方和计算已建立规则；AI理解和分析使用选择的云端接口。初次配置自己的API Key或设备码登录，并主动允许本次发送。

旧电脑中心/LAN方案仅留作 docs/legacy/ 归档，不是本版使用前提。
